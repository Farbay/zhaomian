# create-qa — 创建问答

`POST /open/user/qas` · 鉴权：Bearer apiKey

## 请求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `qaType` | number | 是 | `0` 普通问答、`1` 雷区 |
| `question` | string | 是 | 问题，最长 255 字 |
| `answer` | string | 是 | 回答，最长 255 字 |
| `summary` | string | 是 | 摘要 / 简短回答，最长 255 字，允许空字符串 |

## 响应

| 字段 | 描述 |
|------|------|
| `data.qaId` | 新建问答 ID |

## 注意

- 四个字段都要提交，`summary` 没有值时传空字符串，不要省略该字段。
- 用户没说类型时，默认按普通问答（`qaType=0`）创建，并在回复中说明。
- 创建成功后记录返回的 `qaId`，供后续更新 / 删除使用。
