# cancel-signup — 取消活动报名

`DELETE /open/events/{eid}/submissions/me` · 鉴权：Bearer apiKey

取消当前用户的待审核（含候补）或已通过报名，uid 由 API Key 解析。

## 请求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `eid` | string | 是 | Path 参数，活动 ID（UUIDv7） |

无 Query 参数和请求体。

## 取消规则

- 仅允许活动处于已发布、报名中、报名截止或进行中，且未超过有效结束时间、用户未签到。已通过报名还要求成员存在且状态正常。
- 成功后报名变为已取消；已通过报名同时退出活动。关联的圈子申请仅解除关联，保留自身状态。
- 是否能重新报名取决于活动当前规则，不能因取消成功就承诺可重新报名。

## 响应与处理

| 结果 | 处理方式 |
|------|----------|
| `code=0` | 告知用户已取消报名；最新报名查询返回 `151`，已参加列表不再包含该活动 |
| `150` | 活动不存在或已删除，重新确认目标活动 |
| `151` | 当前没有有效报名记录，可能未报名或已取消；不要解释为从未报名 |
| 其他非 `0` | 转述 `msg`，不要原样重试 |

## 调用流程

1. 用户明确要求取消且活动唯一时直接调用；目标不明确时按 `list-signed-up-events.md` 查询并让用户选择。仅询问能否取消不执行写操作。
2. 以服务端结果为准，成功后不自动重新报名。
3. 网络超时或 HTTP 5xx 时，先按 `get-latest-submission.md` 查询。返回 `151` 表示当前已无有效报名；仍有记录时确认是否为原报名，不自动重试取消，避免误取消新报名。

## 示例

```bash
curl -X DELETE "${FARBAY_OPEN_HOST}/open/events/${EID}/submissions/me" \
  -H "Authorization: Bearer ${FARBAY_OPEN_API_KEY}"
```
