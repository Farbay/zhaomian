# delete-resume — 删除用户履历

`DELETE /open/user/resumes/{resumeId}` · 鉴权：Bearer apiKey

## 请求

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `resumeId` | number | 是 | 履历 ID |

## 业务码

| 业务码 | 说明 |
|--------|------|
| `115` | 用户履历不存在 |
| `121` | 履历实体已被使用 |
| `122` | 用户履历已被引用，不能删除 |

## 注意

1. 先用 `list-resumes.md` 或上下文拿到 `resumeId`，向用户确认要删除的履历。
2. 用户确认后调用本接口。
3. 返回 `122` 说明履历被引用，需提示用户先解除引用再删除。
